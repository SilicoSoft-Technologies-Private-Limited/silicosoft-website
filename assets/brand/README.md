# SilicoSoft brand assets

Upload the official high-resolution logo into this folder with the exact filename:

`silicosoft-logo-hd.png`

After GitHub Pages deploys, the direct public URL will be:

`https://silicosoft.in/assets/brand/silicosoft-logo-hd.png`

Recommended:
- PNG
- Transparent background if possible
- At least 1024 px wide
- Do not rename the file after sharing the URL with ABDM
