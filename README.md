# SilicoSoft Modern Website

A responsive static website designed for GitHub Pages. It includes a scroll-driven homepage, product pages, interactive industry section, enquiry form, privacy page and thank-you page.

## Files
- `index.html` — main website
- `product-hmis.html`, `product-lmis.html`, `product-education.html`, `product-hrms.html` — product landing pages
- `privacy.html` — draft privacy policy
- `thank-you.html` — form confirmation page
- `assets/styles.css` — visual system and responsive styles
- `assets/script.js` — menu, reveal animation and industry tabs

## Enquiry form
The form uses FormSubmit and sends submissions to `hello@silicosoft.in`. On the first live submission, FormSubmit normally sends an activation email to that mailbox. Approve it once. For production-grade control, replace the form action with a SilicoSoft API endpoint and add server-side spam protection, database logging and notification workflows.

## Deploy to GitHub Pages
Copy these files to the repository root, retain the existing `CNAME`, commit and push to `main`. In GitHub: Settings → Pages → Deploy from branch → `main` / root.

## Before launch
Replace unverified claims, add actual company registration/CIN, final address, phone, LinkedIn URL, client logos, case studies, screenshots, support commitments, hosting/security statements and approved privacy/cookie terms.
